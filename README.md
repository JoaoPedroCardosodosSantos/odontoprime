## Sobre o projeto

O **OdontoPrime** é um projeto conceitual de landing page desenvolvido para uma clínica odontológica.

A proposta foi criar uma presença digital moderna, profissional e acolhedora, capaz de apresentar os principais serviços da clínica e, ao mesmo tempo, transmitir segurança para quem está procurando atendimento odontológico.

O projeto foi pensado a partir de uma questão central:

> **Como transformar a primeira visita ao site em uma oportunidade de contato com a clínica?**

---

## O objetivo

Para uma clínica odontológica, o site precisa fazer mais do que apresentar informações.

Ele deve ajudar o paciente a:

- entender os serviços oferecidos;
- conhecer melhor a clínica;
- perceber profissionalismo e credibilidade;
- encontrar informações importantes rapidamente;
- sentir segurança antes de entrar em contato;
- encontrar uma forma simples de agendar uma consulta.

Por isso, a página foi estruturada para combinar **design, clareza de informação e conversão**.

---

## A experiência

A estrutura da página acompanha a jornada de um possível paciente.

### 1. Primeira impressão

O Hero apresenta imediatamente a proposta da clínica e conduz o visitante para a principal ação:

**Agendar uma consulta.**

---

### 2. Serviços

Os principais tratamentos são apresentados de maneira organizada e visualmente clara.

Isso permite que o visitante identifique rapidamente se a clínica oferece o tratamento que procura.

---

### 3. Sobre a clínica

Uma apresentação institucional ajuda a construir proximidade e confiança.

A comunicação procura transmitir uma clínica moderna, profissional e focada na experiência do paciente.

---

### 4. Diferenciais

A página destaca características que podem influenciar a decisão do paciente, como:

- atendimento personalizado;
- profissionais qualificados;
- estrutura moderna;
- tecnologia;
- experiência.

Esses elementos ajudam a transformar características da clínica em argumentos de confiança.

---

### 5. Resultados e prova social

Depoimentos e indicadores são utilizados para reforçar a credibilidade da clínica.

A ideia é reduzir a insegurança comum antes do primeiro contato e mostrar que outros pacientes tiveram uma experiência positiva.

---

### 6. Chamada para ação

Ao longo da página, o visitante encontra chamadas para ação claras.

No final, a comunicação é direcionada novamente para o objetivo principal:

**Agendar uma consulta.**

---

## Design

O visual foi desenvolvido para equilibrar dois conceitos importantes para uma clínica odontológica:

**profissionalismo e acolhimento.**

A identidade visual utiliza:

- bastante espaço em branco;
- tipografia moderna;
- elementos minimalistas;
- imagens relacionadas à odontologia;
- contraste controlado;
- chamadas para ação destacadas.

O resultado busca transmitir uma percepção de clínica moderna e confiável sem criar uma experiência excessivamente fria ou hospitalar.

---

## Responsividade

A página foi desenvolvida para funcionar em diferentes dispositivos.

### Desktop

Maior aproveitamento do espaço horizontal, permitindo uma apresentação mais ampla dos serviços e informações.

### Tablet

O layout se adapta progressivamente para preservar a hierarquia das informações.

### Mobile

Os elementos são reorganizados para uma navegação vertical simples e confortável, com destaque para as principais chamadas para ação.

---

## Interações

A experiência inclui detalhes de interação para tornar a navegação mais fluida:

- navegação suave;
- menu responsivo;
- animações de entrada;
- efeitos de hover;
- transições;
- chamadas para ação destacadas.

As interações foram utilizadas de maneira moderada para complementar a experiência sem comprometer a clareza.

---

## Tecnologias

O projeto foi desenvolvido utilizando:

- **HTML5** — estrutura da página;
- **CSS3** — layout, responsividade e identidade visual;
- **JavaScript** — interações e comportamento da interface;
- **Google Fonts** — tipografia;
- **GitHub Pages** — publicação da demonstração.
